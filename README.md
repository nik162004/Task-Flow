# 🚀 TaskFlow

A modern **Full Stack MERN Task Management Application** that helps users organize and manage daily tasks efficiently.

🌐 **Live Demo:** https://task-flow-ten-lake.vercel.app

📂 **GitHub Repository:** https://github.com/nik162004/Task-Flow

---

## ✨ Features

- 🔐 JWT Authentication
- 👤 User Registration & Login
- 🔒 Protected Routes
- ✅ Create Tasks
- 📋 View Tasks
- ✏️ Update Task Status
- 🗑 Delete Tasks
- 🔍 Search Tasks
- 🎯 Filter Tasks by Status
- 📱 Responsive UI
- ☁️ Fully Deployed

---

## ⚙️ Installation

### Clone repository

```bash
git clone https://github.com/nik162004/Task-Flow.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🔐 Environment Variables

Backend requires:
